# Security Policy Gap Analysis

| Area | Gap | Risk | Priority |
|---|---|---|---|
| Authentication | MFA unclear | Account takeover | High |
| Access Control | Least privilege unclear | Unauthorized access | High |
| Offboarding | Deprovisioning unclear | Former-user access | High |
| Data Protection | Classification/encryption incomplete | Data exposure | High |
| Endpoint | Protection/patching incomplete | Malware | High |
| Incident Response | Reporting/escalation unclear | Delayed response | High |
| Backup | Protection/testing incomplete | Data loss | High |
| Awareness | Recurring training unclear | Phishing | Medium |
| Third Parties | Vendor controls incomplete | Supply-chain risk | Medium |
| Governance | Review/exception process unclear | Outdated controls | Medium |
